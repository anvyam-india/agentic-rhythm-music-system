# Rhythmonic Academy

Frontend-only demo of **Rhythmonic Academy** — Smart Music Learning & Academy Management Platform for Rhythmonic Music Academy & Studio, South Bopal, Ahmedabad.

## Stack

- React + TypeScript + Vite
- React Router
- Tailwind CSS v4
- Lucide React
- Recharts

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Demo flow

1. Open the app → Login
2. Continue as **Admin** → Dashboard → Students → Aarav Patel
3. Switch to **Teacher** → Today's class → mark attendance → add feedback
4. Switch to **Child** → Practice → Practice Analysis (mock AI)
5. Open **Family View** → parent monitoring (attendance, practice, fees)

Everything uses mock data, local state, and localStorage. No backend, payments, or real AI APIs.
